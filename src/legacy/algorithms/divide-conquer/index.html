خوارزميات فرق تسد (Divide & Conquer)

استراتيجية حل المشكلات: تقسيم — حل — دمج

مفهوم خوارزميات فرق تسد

فرق تسد (Divide & Conquer) هي استراتيجية خوارزمية قوية تعتمد على فكرة بسيطة لكنها فعالة: تقسيم المشكلة الكبيرة إلى مشكلات فرعية أصغر، حل كل مشكلة فرعية بشكل مستقل، ثم دمج الحلول الفرعية للحصول على الحل النهائي. هذه الاستراتيجية هي أساس العديد من الخوارزميات الفعالة في علم الحاسوب.

لماذا تعتبر قوية؟

تكمن قوة هذه الاستراتيجية في قدرتها على تحويل المشكلات المعقدة إلى مشكلات بسيطة يمكن حلها بسهولة. باستخدام هذه الطريقة، يمكننا تصميم خوارزميات ذات تعقيد زمني منخفض مثل O(n log n) بدلاً من O(n²)، مما يجعلها مثالية للتعامل مع كميات كبيرة من البيانات.

الخطوات الأساسية لخوارزميات فرق تسد

١

التقسيم (Divide)

تقسم المشكلة الأصلية إلى مشكلات فرعية أصغر حجماً. تكون هذه المشكلات الفرعية مستقلة ومتشابهة في هيكلها للمشكلة الأصلية. يستمر التقسيم حتى تصبح المشكلات الفرعية بسيطة بما يكفي لحلها مباشرة.

٢

الحل (Conquer)

يتم حل كل مشكلة فرعية بشكل منفصل. إذا كانت المشكلة الفرعية صغيرة بما يكفي، يتم حلها مباشرة باستخدام طريقة بسيطة (هذه تسمى الحالة الأساسية). أما إذا كانت أكبر، فيتم تطبيق نفس الاستراتيجية عليها بشكل تكراري.

٣

الدمج (Combine)

تُدمج حلول المشكلات الفرعية معاً للحصول على حل المشكلة الأصلية. تختلف طريقة الدمج حسب نوع الخوارزمية — في ترتيب الدمج نقوم بدمج مصفوفتين مرتبتين، بينما في البحث الثنائي لا توجد حاجة لخطوة دمج.

أمثلة على خوارزميات فرق تسد

١. ترتيب الدمج (Merge Sort)

من أشهر الأمثلة على استراتيجية فرق تسد. تقوم الخوارزمية بتقسيم المصفوفة إلى نصفين متساويين تقريباً، ثم ترتب كل نصف بشكل تكراري، وأخيراً تدمج النصفين المرتبين للحصول على مصفوفة مرتبة بالكامل.

خطوات الخوارزمية ومعادلة التكرار (Recurrence):

  1. إذا كان طول المصفوفة ≤ 1، فهي مرتبة — نعود بها ($$ T(1) = O(1) $$).
  2. نقسم المصفوفة إلى نصفين متساويين.
  3. نطبق الخوارزمية تكراريًا على كل نصف ($$ 2T(n/2) $$).
  4. ندمج النصفين المرتبين في مصفوفة واحدة مرتبة ($$ O(n) $$).
$$ T(n) = 2T\left(\frac{n}{2}\right) + O(n) \implies O(n \log_2 n) $$
function mergeSort(arr) {
  if (arr.length ≤ 1) return arr;
  const mid = Math.floor(arr.length / 2);
  const left = arr.slice(0, mid);
  const right = arr.slice(mid);
  return merge(mergeSort(left), mergeSort(right));
}

٢. الترتيب السريع (Quick Sort)

خوارزمية ترتيب سريعة وفعالة تستخدم أيضاً استراتيجية فرق تسد. تختار الخوارزمية عنصراً محورياً (pivot) ثم تقسم المصفوفة إلى عناصر أصغر من المحور وعناصر أكبر منه، ثم ترتب كل قسم تكراريًا.

خطوات الخوارزمية:

  1. نختار عنصراً محورياً (عادةً آخر عنصر أو أول عنصر).
  2. نقسم المصفوفة حول المحور: الأصغر على اليسار، الأكبر على اليمين.
  3. نطبق الخوارزمية تكراريًا على القسمين الأيمن والأيسر.
  4. ليست هناك حاجة لخطوة دمج — المصفوفة تُرتّب في المكان (in-place).
function quickSort(arr, low, high) {
  if (low < high) {
    const pi = partition(arr, low, high);
    quickSort(arr, low, pi - 1);
    quickSort(arr, pi + 1, high);
  }
}

٣. البحث الثنائي (Binary Search)

خوارزمية فعالة للبحث في مصفوفة مرتبة. تقوم بتقسيم المصفوفة إلى نصفين في كل خطوة، ثم تبحث في النصف الذي يحتمل وجود العنصر المطلوب فيه. هذا يقلل مساحة البحث إلى النصف في كل خطوة.

خطوات الخوارزمية:

  1. نحدد العنصر الأوسط في المصفوفة المرتبة.
  2. إذا كان العنصر الأوسط هو المطلوب — نعيد موقعه.
  3. إذا كان المطلوب أصغر — نبحث في النصف الأيسر.
  4. إذا كان المطلوب أكبر — نبحث في النصف الأيمن.
  5. نكرر حتى نجد العنصر أو يصبح نطاق البحث فارغاً.
function binarySearch(arr, target) {
  let left = 0, right = arr.length - 1;
  while (left ≤ right) {
    const mid = Math.floor((left + right) / 2);
    if (arr[mid] === target) return mid;
    if (arr[mid] < target) left = mid + 1;
    else right = mid - 1;
  }
  return -1;
}

ملاحظة مهمة

النجاح الأساسي لاستراتيجية فرق تسد هو في تقليل التعقيد الزمني من O(n²) إلى O(n log n) في العديد من الحالات. هذا التحسن الهائل يجعل الخوارزميات مثل Merge Sort قادرة على ترتيب ملايين العناصر بكفاءة عالية. مفتاح النجاح هو اختيار طريقة التقسيم المناسبة وطريقة الدمج الفعالة.
