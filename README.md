# مقرر الحاسوب — Next.js

نسخة مستقلة من موقع مقرر الحاسوب. ملفات الموقع الأصلي موجودة في المجلد الأعلى وتبقى كما هي؛ هذا المشروع يحتفظ بنسخة قراءة من صفحات HTML وملفات CSS/JS القديمة داخل `src/legacy` و`public/legacy` إلى أن تُنقل محاكياتها تدريجيًا إلى مكونات React مستقلة.

## التشغيل

- Node.js 20.9 أو أحدث.
- `npm install`
- `npm run dev`

قبل التطوير أو البناء يُولّد Tailwind ملفًا محليًا لصفحات التجربة المحفوظة. لا تعتمد صفحة Next.js الجديدة على Tailwind CDN.

## الصفحات

- `/` صفحة المقرر الرئيسية.
- `/algorithms` مكتبة المواضيع.
- `/algorithms/[slug]` شرح الموضوع.
- `/algorithms/[slug]/simulation` محاكاته.
- `/algorithms/[slug]/code` أمثلة الكود.

تُحوّل مسارات `.html` القديمة إلى المسارات الجديدة في `next.config.ts`.

## قرار الترحيل

تعمل الصفحات القديمة داخل `iframe` معزول في هذه المرحلة حتى لا تتعارض متغيرات JavaScript العامة بين المحاكيات عند تنقل App Router. تُنقل كل محاكاة لاحقًا إلى محرك TypeScript ومكوّن React خاصين بها بعد تثبيت نتائجها المرجعية.
